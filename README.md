# Top Racer : Ghost Lap (2주차)

라즈베리파이 + Adafruit 1.3" TFT 보넷(240x240)용 탑뷰 타임어택 레이싱 게임.
상대는 과거의 나: 최고 랩이 반투명 고스트로 같이 달려요.
PC에서도 pygame 창으로 똑같이 실행돼요.

## 실행

**파이**
```bash
source ~/env/bin/activate
cd ~/top-racer
python main.py          # 종료: Ctrl+C
```

**PC (Windows)**
```powershell
pip install pillow numpy pygame
python main.py          # 종료: Esc
```

## 조작

| | 파이 | PC |
|---|---|---|
| 조향 | 조이스틱 좌/우 | ← → |
| 가속 | A 버튼 | Z 또는 Space |
| 브레이크/후진 | B 버튼 | X |
| 드리프트 | 빠르게 달리며 B + 조향 | X + 방향키 |
| 부스트 | 조이스틱 위 | ↑ |
| 일시정지 | 조이스틱 가운데 | Enter |

- 일시정지 메뉴: CONTINUE / RESPAWN(마지막 체크포인트로) / RESTART / TITLE (위·아래로 고르고 A)
- 결과 화면: A = 다시 달리기, B = 타이틀로

## 게임 규칙

- 시작 화면 → 3, 2, 1, GO! → 3바퀴 → FINISH! → 결과 화면
- 체크포인트를 순서대로 다 지나야 한 바퀴로 인정 (지름길, 출발선 왕복 X), 거꾸로 달리면 WRONG WAY
- **드리프트**: 미끄러지는 동안 아래쪽 부스트 게이지(3칸)가 차요. 잔디·벽에 닿으면 게이지를 잃어요
- **부스트**: 게이지 1칸을 써서 1.5초 동안 더 빨라져요 (차 뒤에 불꽃)
- **고스트**: 최고 랩을 달렸던 경로가 파란 반투명 차로 같이 달려요. 최고 랩을 깨면 바로 새 고스트로 바뀌어요
- **구간 기록**: 체크포인트를 지날 때마다 화면 위에 최고 랩과의 차이 표시 (초록 -0.42 = 더 빠름, 빨강 +0.31 = 더 느림)
- 물리는 항상 1/60초 간격 → PC와 파이에서 같은 주행이면 같은 기록

## 기록 저장

- `save_data.json`에 트랙별 최고 총 기록, 최고 랩, 구간 기록, 고스트를 저장 (git에는 안 올라가요)
- 파일이 깨지면 `save_data.json.bak`으로 옮겨 두고 빈 기록으로 시작
- `config.py`의 물리 값이나 트랙 모양을 바꾸면 예전 기록은 자동으로 무시 (다른 규칙으로 달린 기록이라서)
- 기록을 지우고 싶으면 `save_data.json` 파일만 지우면 돼요

## 파일

| 파일 | 내용 |
|---|---|
| `config.py` | 모든 수치 (조작감, 드리프트/부스트, 레이스 진행, 개발용 옵션) |
| `tracks.py` | 트랙 데이터 (모양, 랩 수, 체크포인트 수, 색, 메달 기준) |
| `track.py` | 트랙 그림 + 판정 마스크 (0=벽, 1=잔디, 2=도로) + 중심선 계산 |
| `race.py` | 랩, 시간, 체크포인트, 역주행 판정 |
| `ghost.py` | 고스트 녹화와 보간 재생 |
| `save.py` | 기록 저장/불러오기 (JSON) |
| `states.py` | 화면 상태 (시작, 카운트다운, 레이스, 일시정지, 결과) |
| `car.py` | 차량 물리, 드리프트, 부스트, 회전 이미지 |
| `camera.py` | 룩어헤드 카메라 |
| `hud.py` | 레이스 화면 정보 (랩, 시간, 구간 차이, 게이지, 알림) |
| `ui.py` | 폰트, 글자 그리기, 시간 형식 |
| `hardware.py` | 보넷 / pygame 입출력 |
| `main.py` | 게임 루프 (고정 시간 간격 물리) |

## 개발용 옵션 (`config.py`)

- `DEBUG_CHECKPOINTS = True` → 트랙에 체크포인트 위치를 노란 선과 번호로 표시
- `SHOW_FPS = False` → 오른쪽 아래 FPS 숨기기
- 드리프트/부스트 손맛은 `DRIFT_*`, `BOOST_*` 값으로 조절
