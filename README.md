# Top Racer : Ghost Lap

라즈베리파이 + Adafruit 1.3" TFT 보넷(240x240)용 탑뷰 타임어택 레이싱 게임.
상대는 과거의 나: 최고 랩이 반투명 고스트로 같이 달려요. 세 트랙 모두 금메달이 목표예요.
PC에서도 pygame 창으로 똑같이 실행돼요.

## 실행

**파이**
```bash
source ~/env/bin/activate
cd ~/top-racer
python main.py          # 종료: Ctrl+C
```

**PC (Windows)**
```powershell
pip install pillow numpy pygame
python main.py          # 종료: Esc
```

## 조작

| | 파이 | PC |
|---|---|---|
| 조향 | 조이스틱 좌/우 | ← → |
| 가속 | A 버튼 | Z 또는 Space |
| 브레이크/후진 | B 버튼 | X |
| 드리프트 | 빠르게 달리며 B + 조향 | X + 방향키 |
| 부스트 | 조이스틱 위 | ↑ |
| 일시정지 | 조이스틱 가운데 | Enter |

**조작 방식** (`config.py`의 `CONTROL_MODE`, 기본 `"rotate"`)

| 모드 | 화면 | 조향 | 부스트 / 일시정지 |
|---|---|---|---|
| `"rotate"` (기본) | 차를 따라 돌아서 차가 항상 위를 봐요 | 좌/우 = 운전석 기준 좌/우 | 위 / 가운데 |
| `"absolute"` | 고정 (북쪽이 위) | 조이스틱을 민 화면 방향으로 차가 돌아요 (위·아래도 조향) | 가운데 짧게 / 가운데 길게(0.6초) |
| `"classic"` | 고정 | 좌/우 = 차 기준 회전 (예전 방식) | 위 / 가운데 |

- `rotate`에서 화면이 너무 빨리/느리게 돌면 `CAMERA_TURN_SMOOTH`, 파이에서 느리면 `CAMERA_ROTATE_FAST = True`
- `absolute`에서 후진(B) 중엔 차 뒤쪽이 조이스틱 방향으로 가요. 드리프트는 차 방향과 다른 쪽으로 조이스틱 + B
- 조작 방식을 바꿔도 저장된 기록은 그대로예요

- 트랙 선택: 좌/우로 넘기고 A로 출발, B로 타이틀
- 일시정지 메뉴: CONTINUE / RESPAWN(마지막 체크포인트로) / RESTART / TRACKS (위·아래로 고르고 A)
- 결과 화면: A = 다시 달리기, B = 트랙 선택

## 게임 흐름과 규칙

시작 화면 → 트랙 선택 → 3, 2, 1, GO! → 3바퀴 → FINISH! → 결과 (메달) → … → ALL GOLD!

- **트랙 3개**: 순서대로 열려요. 앞 트랙에서 동메달 이상을 따면 다음 트랙 해금

  | 트랙 | 특징 |
  |---|---|
  | Sunny Circuit | 낮, 넓은 도로, 완만한 코너 (연습용) |
  | Coast Line | 해질녘 해안 도로. 도로가 좁고 코너 바깥에 모래 (밟으면 크게 느려짐), 아래쪽은 바다 |
  | Night City | 야간 도심. 가장 길고 S자 코너와 헤어핀, 도로 밖 건물은 벽. 금메달 기준이 가장 빡빡함 |

- **메달**: 3바퀴 총 기록이 트랙별 기준 안이면 금/은/동 (기준은 트랙 선택 화면 아래에 표시)
- **ALL GOLD**: 세 트랙 모두 금메달을 처음 달성하면 엔딩 화면
- 체크포인트를 순서대로 다 지나야 한 바퀴로 인정 (지름길, 출발선 왕복 X), 거꾸로 달리면 WRONG WAY
- **드리프트**: 미끄러지는 동안 아래쪽 부스트 게이지(3칸)가 차요. 잔디·모래·벽에 닿으면 게이지를 잃어요
- **부스트**: 게이지 1칸을 써서 1.5초 동안 더 빨라져요 (차 뒤에 불꽃)
- **고스트**: 최고 랩 경로가 파란 반투명 차로 같이 달려요. 최고 랩을 깨면 바로 새 고스트로
- **구간 기록**: 체크포인트마다 화면 위에 최고 랩과의 차이 (초록 -0.42 = 더 빠름, 빨강 +0.31 = 더 느림)
- **미니맵**: 오른쪽 아래. 빨간 점 = 내 차, 파란 점 = 고스트, 노란 선 = 출발선
- 물리는 항상 1/60초 간격 → PC와 파이에서 같은 주행이면 같은 기록

## 기록 저장

- `save_data.json`에 트랙별 최고 총 기록, 최고 랩, 구간 기록, 고스트, 해금 상태를 저장 (git에는 안 올라가요)
- 파일이 깨지면 `save_data.json.bak`으로 옮겨 두고 빈 기록으로 시작
- `config.py`의 물리 값이나 트랙 모양을 바꾸면 예전 기록은 자동으로 무시 (해금은 유지)
- 처음부터 다시 하려면 `save_data.json` 파일만 지우면 돼요

## 파일

| 파일 | 내용 |
|---|---|
| `config.py` | 모든 수치 (조작감, 드리프트/부스트, 모래, 레이스 진행, 개발용 옵션) |
| `tracks.py` | 트랙 데이터 (모양, 크기, 도로 폭, 색, 장식, 메달 기준) |
| `track.py` | 트랙 그림 + 판정 마스크 (0=벽, 1=잔디, 2=도로, 3=모래) + 중심선 계산 + 미니맵 |
| `race.py` | 랩, 시간, 체크포인트, 역주행 판정 |
| `ghost.py` | 고스트 녹화와 보간 재생 |
| `save.py` | 기록 저장/불러오기 (JSON) |
| `progress.py` | 메달, 트랙 해금, ALL GOLD 판정 |
| `states.py` | 화면 상태 (시작, 트랙 선택, 카운트다운, 레이스, 일시정지, 결과, 엔딩) |
| `car.py` | 차량 물리, 드리프트, 부스트, 회전 이미지 |
| `camera.py` | 룩어헤드 카메라 (rotate 모드에선 화면 회전 각도도) |
| `hud.py` | 레이스 화면 정보 (랩, 시간, 구간 차이, 게이지, 미니맵, 메달 아이콘) |
| `ui.py` | 폰트, 글자 그리기, 시간 형식 |
| `hardware.py` | 보넷 / pygame 입출력 |
| `main.py` | 게임 루프 (고정 시간 간격 물리), 로딩 화면, 성능 측정 |

## 개발용 옵션 (`config.py`)

- `PROFILE = True` → 5초마다 터미널에 FPS와 시간 출력 (update=입력+물리, draw=그림, show=화면 전송)
- `SPI_BAUDRATE` → 파이에서 show 시간이 크면 `40_000_000` 정도로 올려보기 (화면이 깨지면 다시 낮추기)
- `DEBUG_CHECKPOINTS = True` → 트랙에 체크포인트 위치를 노란 선과 번호로 표시
- `SHOW_FPS = False` → 오른쪽 아래 FPS 숨기기
- 드리프트/부스트 손맛은 `DRIFT_*`, `BOOST_*` 값으로 조절
